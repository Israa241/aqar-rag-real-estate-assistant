# Aqar | عقار

An Arabic-English AI real estate assistant for Riyadh.

## Features

- Answers real estate questions in Arabic and English
- Uses a PDF as a knowledge base
- Built with RAG, LangChain, ChromaDB, Gemini, Groq, and Streamlit
